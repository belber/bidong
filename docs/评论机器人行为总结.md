# 评论机器人（@壁咚咚私藏）行为总结

> 状态：2026-09-27 现行行为 ｜ 设计依据：`docs/spec.md` §7
> 用途：运营/排障时对照——**用户做了什么、机器人回什么、不做什么**。
> 全文行为都以代码为准（`server/app/robot/worker.py`、`server/app/services/activation.py`）。

---

## 0. 一句话

机器人只做两件事：**看到新粉丝 → 私信发激活码**；**看到有人 @ 它 → 把那个视频存进对方的收藏夹**。
除此之外只在 @ 的场景下回私信，**不进评论区**。

---

## 1. 两条轮询链路

| 链路 | 接口 | 默认频率 | 干什么 |
|:--|:--|:--|:--|
| 粉丝列表 | `x/relation/followers` | 30s（可调） | 发现新粉丝 → 私信激活码 |
| 评论 @ | `x/msgfeed/at` | 30s（可调） | 有人 @ → 触发收藏 |

两条都要机器人账号的 Cookie（`SESSDATA / bili_jct / DedeUserID / buvid3 / buvid4`）。
Cookie 失效会同时打断两条链路，管理端有失效告警（只在"曾经有效→本次失效"时告警，避免首次配置误报）。

---

## 2. 触发点一：关注机器人

**滑动窗口**：只处理"最近 30 分钟内关注"的人（`follow_window`，可调）。
更早关注的人**不入发码逻辑**，只记一条 `follow_event` 用于统计。

| 情况 | 机器人行为 |
|:--|:--|
| 新粉丝，没绑定过 | 生成/复用激活码 → 私信发码 |
| 新粉丝，已经绑定过 | 私信"你已经绑定过啦，打开小程序即可查看" |
| 老粉丝（30 分钟前关注） | **不发**，只记统计 |
| 同一个人短时间内重复出现（`mtime` 没变） | **不发**（靠 `last_follow_mtime` 判重） |
| 取关后再关注 | `mtime` 变化 → **重发同一个码**（一个 B站 UID 只有一个码，防刷码） |

**私信文案**

```
① 你的激活码：{码}
   复制整条消息，打开「壁咚咚藏链阁」小程序粘贴即可绑定 ✨

② 你已经绑定过「壁咚咚藏链阁」啦，无需重复绑定。
   打开「壁咚咚藏链阁」小程序，即可查看收藏的视频。
```

**写库**：`binding`（码 ↔ B站 UID，`bili_uid` 唯一）、`follow_event`（每次关注一条，按 `(uid, mtime)` 去重）、
`activation_log`（每次发码尝试一条，含失败原因）。

---

## 3. 触发点二：评论区 @ 机器人

**判断顺序**（每一步都可能提前结束）：

```
新 @ 通知（按 feed_id 去重，处理过的跳过）
   │
   ├─ 这个 UID 有「已绑定」的 binding？
   │      │
   │      ├─ 有 → 解析视频 → 收藏到他的收藏夹（幂等：同一视频不重复建卡）
   │      │        └─ 收藏成功 → 回收藏确认私信
   │      │        └─ 收藏失败 → 不回私信，只记「解析失败」
   │      │
   │      └─ 没有 → 看有没有 binding 行（= 关注过没）
   │              ├─ 关注过（有 binding、没绑定）→ 重发同一个激活码
   │              └─ 没关注过（没有 binding 行）→ 引导关注（不发码）
```

### 私信文案（@ 场景，全部走私信）

```
③ 已绑定、收藏成功：
   「{视频标题}」已收藏到「壁咚咚藏链阁」✅ 打开小程序就能看到

④ 已关注但没绑定：
   你的激活码：{码}
   复制整条消息，打开「壁咚咚藏链阁」小程序粘贴即可绑定 ✨
   （和文案 ① 完全一致，复用同一个码）

⑤ 没关注：
   想让我自动帮你收藏视频？先关注我 ✨
   关注后我会自动私信你激活码，去「壁咚咚藏链阁」小程序「我的 → 绑定」粘贴即可。
```

### 不回私信的情况

| 情况 | 说明 |
|:--|:--|
| 收藏失败（视频被删 / B站接口异常） | 只记 `解析失败`，避免把失败做成噪音 |
| 24h 内已经回过他（未绑定场景） | 记 `未绑定·24h内不重复` |
| 24h 内已回满 3 条（已绑定场景） | 记 `已收藏·回复达上限` |
| 发送被 B站拦（风控） | 记 `回复失败 + 原因`，**不自动重试** |

**为什么收藏成功后要回**：不回的话用户不确定成功没成功，会**再 @ 几条试探**——
重复 @ 反而制造更多互动量，风控暴露更大。回一条确认能让他立刻停手。

**为什么只在私信、不进评论区**：评论区回复更公开（自带宣传效果），但被判"刷屏/引流"的风险高得多。

## 4. 频控与开关

| 项 | 值 |
|:--|:--|
| 未绑定场景（引导关注 / 重发码） | 同一 UID **24 小时最多回 1 条** |
| 已绑定场景（收藏确认） | 同一 UID **24 小时最多回 3 条** |
| 每次私信之间 | 间隔 `send_interval`（默认 5s），避免连发 |
| 总开关 | 管理端「功能开关 → @ 自动回复」，默认**开**；风控一响一键关 |

关掉总开关后行为退回"静默"：@ 只记 `未绑定/已收藏`，不发任何私信，收藏主链路不受影响。

---

## 5. 管理端能看到什么

| 页面 | 看什么 |
|:--|:--|
| 概览 | 机器人关注与绑定：今日新增关注 / 关注总数 / 已绑定 / 转化率 / 今日发码成功 |
| 关注监控 | 每个粉丝的来源、`mtime`、是否发码成功、是否已绑定（含发码失败原因） |
| 评论@监控 | 每条 @ 的发送者、视频、**处理结果**、失败原因 |
| 功能开关 | @ 自动回复总开关 |
| 定时任务 | 两条轮询间隔、发码间隔、关注发码窗口 |
| 账号/Cookie | Cookie 状态、更新 Cookie、手动校验 |

**评论@监控里的结果值**（对照排障用）：

| 显示 | 含义 |
|:--|:--|
| 已收藏·已回复 | 收藏成功，且回了确认私信 |
| 已收藏·回复达上限 | 收藏成功，但 24h 内已回满 3 条，没再回 |
| 已回复激活码 | 已关注未绑定，重发了激活码 |
| 已回复关注引导 | 没关注，回了引导 |
| 未绑定·24h内不重复 | 24h 内回过他，这次不回 |
| 未绑定 | @ 自动回复开关关着（静默模式） |
| 解析失败 / 异常 | 收藏没成功，未回私信 |
| 回复失败 | 私信发送被拦（风控/接口异常），右侧有原因 |

## 6. 运维要点

1. **Cookie 是命门**：失效即两条链路全断。管理端会告警；重新扫码登录后把 Cookie 更新进去。
2. **⚠️ 粉丝列表可见性**：B站账号如果设了"粉丝列表不可见"，粉丝接口会返回
   `code=22118 由于该用户隐私设置，粉丝列表不可见`，**发码链路直接失效**。
   修法：B站 App → 我的 → 设置 → 隐私设置 → 把粉丝列表改成所有人可见。
3. **观察风控**：出现 `回复失败` 且原因是风控类，立刻关掉「@ 自动回复」开关，收藏功能不受影响。
4. **小规模试点**：用一次性小号、低频、单账号；机器人整体可随时下线（`ROBOT_ENABLED=false`）。
5. **@ 处理是尽力而为**：轮询游标处理完就推进，**单条失败不会自动重试**（下次同一视频再 @ 会重新处理）。
6. **收藏是幂等的**：同一个用户重复 @ 同一个视频，不会重复建卡（`(user_id, bvid)` 唯一）。

## 7. 配置项速查

| 配置 | 位置 | 默认 | 说明 |
|:--|:--|:--|:--|
| `ROBOT_ENABLED` | env | false | 机器人总开关 |
| 关注轮询 / @轮询间隔 | 管理端「定时任务」 | 30s | 两条链路频率 |
| 发码间隔 | 管理端「定时任务」 | 5s | 每次私信之间的间隔 |
| 关注发码窗口 | 管理端「定时任务」 | 1800s | 只给这段时间内关注的人发码 |
| `@ 自动回复` | 管理端「功能开关」 | 开 | 关掉 = 静默模式 |
| Cookie | 管理端「账号/Cookie」 | — | 失效即两条链路全断 |

---

## 8. 已知限制 / 待办

- 评论区 @ 依赖 B站非公开接口（`x/msgfeed/at`），有接口变更风险；接口地址集中配置，改配置不改逻辑。
- 取关后重新关注会重发同一个码（这是防刷码的设计，不是 bug）。
- 老粉丝（机器人上线前就已关注）永远拿不到码，只能取关再关注——**当前不存在这种粉丝**（机器人是专用账号）。
- 管理端「评论@监控」只按结果分类，暂时看不出"回复被限流的比例随时间变化"，需要时再加统计。
