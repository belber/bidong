## 3. 定稿决策

- **只放解析出的信息**：封面 / 标题 / UP主 / 分区 / BV号 / 收藏时间 / 简介 / 固有标签 / 字幕。**不放播放 / 点赞等统计**（spec 未存储）。
- **解析即自动收藏**：不设「保存到收藏夹」按钮，默认已收藏。
- **跳转按钮在封面右下角**，文案「↗ 去查看」，点击拉起微信里的 B站小程序查看原视频。
- **标签区展示的是解析出的固有标签**（视频自带 `#xxx`），不是用户手动贴的收藏标签。
- **固有标签落库**：解析后自动写入 `card_tag` 预填，作为该视频的一个**默认分组**，用户可在收藏夹/卡片上再增删。
- **字幕区**：预览几条 + 「查看更多」+「下载字幕」。无字幕则整块不显示。
- **字段精简**：BV号 + 收藏时间压成一行；简介截断两行。

## 4. 解析结果页字段对照（`video_card`）

| 字段 | 展示位置 |
|:--|:--|
| `cover_url` | 顶部封面（右下角「去查看」+ 时长角标） |
| `title` | 标题（两行截断） |
| `up_name` | UP主 |
| `partition`（tname） | 分区标签 |
| `bvid` | BV号（与收藏时间同行） |
| `desc` | 简介（截断） |
| `collected_at` / `month` | 收藏时间 YYYY-MM · MM-DD |
| `source_url` | 「↗ 去查看」跳转 |

> 固有标签与字幕来自解析时的附加读取：固有标签 `x/tag/archive/tags`（匿名可读，落库 `card_tag`）；字幕 `x/player/wbi/v2`（需 wbi 签名，展示预览 + 下载）。

交互（定稿）：
- **统一卡片**：@壁咚 进来的也是**后台解析完才展示**，不存在「待解析」状态；卡片都带完整信息（封面/标题/UP主/分区/固有标签/来源角标）。

- 未绑定 banner 仅在未绑定 @壁咚时显示，绑定后消失。

交互与子页（定稿）：
- **绑定卡片**：未绑定 → 两步说明 +「去绑定」按钮；已绑定 → 显示 B站 UID/昵称 +「解绑」（二次确认）。
- **帮助与反馈**（子页）：

  ```ascii
  │ 帮助与反馈
  ├────────────────────────────────────────┤
  │  ✉ 意见反馈      → 微信官方反馈组件      │
  │  💬 联系我        → 客服会话             │
  │  🐧 进 QQ 群      → 群号 + [复制群号]    │
  ```

  - 意见反馈：`open-type="feedback"`（微信自带，不自建后台）。
  - 联系我：`open-type="contact"`（客服消息，后台绑定客服微信）。
  - 进 QQ 群：展示群号 +「复制群号」按钮，提示去 QQ 搜索群号申请加入；群号建议后端下发（群满/解散可换），并要求群设置允许「通过群号搜索」。
- **关于 壁咚视频助手**（子页）：logo + 版本号、产品理念说明（只存元数据不下载视频）、使用指引（贴链接解析 / @壁咚收藏夹 两条路径）、联系方式。
- **隐私政策与用户协议**：**合并为单个菜单**，页面内分「用户协议」/「隐私政策」两段；微信后台的「隐私保护指引」仍单独配置（提审必填）。
- **无「清除缓存」**：微信小程序不需要用户手动清理缓存。
