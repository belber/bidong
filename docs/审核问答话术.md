# 小程序第三方审核 · 问答话术

> 用途：配合微信小程序第三方审核 / 备案审核，接听审核公司电话、回复邮件时使用。
> 原则：**如实回答、口径统一、不夸大、不承诺**。遇到不确定的问题，先记下问题再回复，不要现场编造。

---

## 一、产品一句话说明（先背熟）

> 「壁咚咚藏链阁」是一个 B站视频收藏整理工具：用户粘贴 B站链接后，我们把视频的**标题、封面、UP主、分区等元数据**存成卡片，支持**标签分类、按收藏月份分组、跳回 B站查看原视频**；同时作为可开关的增值能力，提供**有水印/无水印视频、纯音频的中转下载**，以及**弹幕、字幕导出**。视频/音频本体**不在服务端长期存储**，按需通过后端中转获取。产品与 B站无官方合作关系，独立开发运营。

---

## 二、产品真实功能清单（口径依据）

| 功能 | 是否开放 | 说明 |
|:--|:--|:--|
| 粘贴链接解析元数据 | ✅ | 标题 / 封面 / UP主 / 分区 |
| 收藏卡片 | ✅ | 自动收藏，同一用户同一视频幂等 |
| 标签 / 月份分组 | ✅ | 分组 = 标签，月份按收藏时间派生 |
| 跳转 B站查看原视频 | ✅ | 拉起 B站官方小程序 |
| 有水印视频下载 | ⚙️ 开关 | 后台开关控制，中转流式 |
| 无水印视频下载 | ⚙️ 开关 | 后台开关控制，风险较高，可关闭 |
| 纯音频下载 | ⚙️ 开关 | 后台开关控制 |
| 弹幕 / 字幕导出 | ⚙️ 开关 | 文本导出 |
| @机器人自动收藏 | 🧪 小规模试点 | Phase 1，低频监听 |

> **提示**：话术必须跟随后台开关的真实状态。审核前建议先确认哪些开关开着，再照着说。

## 三、高频问题与参考答复

### 1. 你是谁？你是这个小程序的负责人吗？
- 「我是 / 代表该小程序的实际运营负责人，主体和备案信息一致。」
- 准备好：备案用的**手机号、邮箱、小程序 AppID、主体名称**。

### 2. 小程序主要做什么？
- 参考「一、产品一句话说明」完整背出。

### 3. 名字为什么叫「壁咚咚藏链阁」？和 B站什么关系？
- 「名称中的『小破站』是用户对 B站的口语化称呼。我们是独立开发的工具，**与 B站没有官方合作或授权关系**；如名称或描述涉及品牌合规问题，我们愿意按平台要求调整。」

### 4. 你们能下载 B站视频吗？
- 「**能，但是受限、可选、可关停的增值能力**：有水印/无水印视频和纯音频都通过**后端中转**获取，视频本体**不长期存储在服务端**，由后台开关控制，可以随时关闭。」
- ⚠️ 不要说「所有视频都能下载」「能突破会员限制」「随意抓取」。
- 如果后台暂时关闭了某档，就说「该功能当前未开放」。

### 5. 视频内容有版权吗？你们有授权吗？
- 「视频画面、封面、标题等版权归**原作者或 B站**所有。我们只保存元数据用于用户个人收藏整理，下载能力也定位为**个人使用**，不提供批量抓取、商用分发。」
- 「未与 B站建立授权关系，仅调用其公开接口；B站接口变更时功能可能失效，我们在用户协议中已作免责说明。」

### 6. 你们收集哪些用户信息？存哪里？
- 「微信登录后的 **openid**（用于识别账号）、用户主动粘贴的 **B站链接**、用户的收藏数据（标题/封面/UP主/分区/标签/收藏时间）。」
- 「封面缩略图转存到**腾讯云 COS**，业务数据存**腾讯云服务器**；视频/音频本体不长期存储。」
- 「剪贴板内容**仅在用户点击『从剪贴板粘贴』时**读取，用于填入链接。」

### 7. 是否涉及第三方 SDK / 服务？
- 微信小程序官方能力（登录、下载、跳转小程序）；
- B站公开接口（解析元数据）；
- B站机器人账号（Phase 1 @ 自动收藏试点）；
- 腾讯云 COS / 服务器。
- 「以上均为提供服务所需，不外售、不共享用户个人信息（法律要求除外）。」

### 8. 有没有用户协议和隐私政策？
- 「有，小程序内有『隐私与协议』页面。」（位置：我的 → 关于 → 隐私与协议）
- ⚠️ **注意**：现协议只写了“保存元数据”，如果下载功能开放，**建议同步补充下载、版权、免责说明**，与真实功能保持一致。

### 9. 你们和审核方/客服怎么联系？
- 准备好一个**能接通的真实手机号**，审核期内保持畅通；
- 如果留的是备用联系方式，也要有人能接。

### 10. 收到审核问题但不确定怎么答怎么办？
- 「该问题涉及具体功能细节，我确认后回复您。」然后**记录下来**，核实代码/后台开关后再答复。
- 不要当场猜、不要编造。

## 四、接电话时的标准流程

1. **先确认对方身份**：记录公司名、工号/姓名、联系方式；
2. **用上面的话术**，简短、有条理地答；
3. **不确定的记下来**，不要瞎答；
4. 要求提供书面材料时，确认**发送邮箱和截止时间**；
5. 审核期间建议**设闹钟提醒每天查看一次**短信/邮件/未接来电。

---

## 五、审核前自查清单

- [ ] 隐私政策 / 用户协议是否与实际功能一致（尤其“下载”能力）
- [ ] 后台下载开关状态确认（开哪些、可答哪些）
- [ ] 备案手机号、邮箱真实可用，有人接听
- [ ] 「我的 → 帮助与反馈 → 联系我」联系方式有效
- [ ] 高风险功能（如无水印视频、音频）审核期是否先关闭
- [ ] 产品介绍里没有「下载 B站所有视频 / 去水印 / 绕过会员」等表述
- [ ] 准备一份《产品功能说明》PDF/文档备用

---

## 六、一句话避坑提醒

> 审核问「能下载吗」→ 如实说「可以，但受控、可选、不长期存储、可随时关闭」；
> 审核问「有授权吗」→ 说「独立开发，无官方授权」；
> 审核问「会不会侵权」→ 说「仅个人收藏使用，内容版权归原作者/B站」。
